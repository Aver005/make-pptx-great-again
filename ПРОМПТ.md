# Задание для нейросети

Скопируйте всё, что ниже между строками `---НАЧАЛО---` и `---КОНЕЦ---`, вставьте
в чат (ChatGPT, DeepSeek, GigaChat, Claude) и допишите свою тему в первой строке.
В ответ придёт HTML — его нужно принести в MPGA.

В самом MPGA для этого есть кнопка «Скопировать задание для нейросети»: она даёт
ровно этот текст.

---НАЧАЛО---
Сделай презентацию на тему: «ВПИШИТЕ ТЕМУ». Количество слайдов: 10.

Ответ дай одним HTML-файлом целиком, без пояснений до и после кода.
Файл будет превращён в PowerPoint автоматической программой, поэтому строго
соблюдай правила ниже — иначе слайды поедут.

ПРАВИЛА ФАЙЛА
1. Один файл: <!doctype html>, весь CSS внутри одного тега <style> в <head>.
2. Первой строкой в <head> добавь: <meta name="mpga-contract" content="1">
3. Ничего не подключай из интернета: ни шрифтов, ни библиотек, ни картинок по
   ссылке. Никаких <script src=...>, <link rel=stylesheet href=...>, <img src="http...">.
4. Шрифт только такой: font-family: Arial, sans-serif.

СЛАЙДЫ
5. Каждый слайд — <section class="slide">. Ровно 10 штук подряд, без обёрток
   вокруг них, кроме одного общего <main>.
6. Размер слайда задай один раз в CSS:
   .slide{width:1160px;height:652.5px;position:relative;overflow:hidden;
   background:#fff;margin:0 auto 24px;padding:44px 62px;box-sizing:border-box}
   Не используй vw, vh, %, min(), max(), calc() от ширины окна и медиазапросы:
   размер слайда должен быть постоянным.
7. Всё содержимое слайда должно помещаться внутрь этих 1160×652.5 с запасом.
   Не рассчитывай на прокрутку.

ЧТО МОЖНО
8. Текст: h1, h2, p, b, span, small, li. Выделение — <b> внутри абзаца.
9. Раскладка: display:flex и display:grid, position:absolute внутри слайда.
10. Фигуры: обычные div с background, border, border-radius.
11. Иконки: <i data-lucide="имя"></i> — названия из набора lucide
    (globe, database, library, search, file-text, users, book-open, check,
    lightbulb, target, settings, chart-line и другие). Ничего подключать не надо.
12. Схемы и диаграммы: inline <svg viewBox="0 0 900 290"> прямо в слайде.
    Подписи внутри схемы делай тегом <text> — они останутся редактируемыми.

ЧЕГО НЕЛЬЗЯ
13. Градиенты (linear-gradient), тени (box-shadow), полупрозрачность (rgba с
    альфой, opacity), фильтры, анимации — их PowerPoint не получит.
14. transform: rotate/scale у блоков с текстом.
15. Картинки-фотографии. Иллюстрируй иконками и схемами.
16. Таблицы через <table> — вместо них сетка из div.

ТЕКСТ
17. Короткие подписи (в карточках, на схемах) пиши так, чтобы они помещались в
    одну строку своей ширины. Лучше 2–3 слова.
18. Длинные абзацы — только в широких блоках на всю ширину слайда.
19. Язык — русский. Никакой латиницы кроме названий и терминов.

СОДЕРЖАНИЕ
20. Слайд 1 — титульный: тема, подзаголовок, автор.
21. Слайды 2–9 — раскрытие темы: определения, классификации, схема процесса,
    примеры, сравнение, выводы. Разнообразь: где-то сетка карточек, где-то
    список, где-то схема.
22. Слайд 10 — заключение.
23. На каждом слайде: короткий заголовок (h2) и не больше 60 слов текста.
---КОНЕЦ---
