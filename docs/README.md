# HTML -> редактируемый PPTX: материалы для продолжения

Этот каталог фиксирует состояние работы на точке передачи другому агенту.
Задача проекта: агент по инструкции собирает презентацию в HTML, а софт
конвертирует структурно верный HTML в PPTX, где текст и фигуры редактируются
как родные объекты PowerPoint, а не вставлены картинкой.

Рабочий прототип конвертера уже есть и проверен на реальной презентации из 10
слайдов. Он лежит в родительском каталоге: [`../build_pptx.py`](../build_pptx.py)
и [`../extract.js`](../extract.js). Прототип не привязан к содержимому конкретной
презентации: он обходит произвольный HTML и строит объекты по измеренной
геометрии.

## Что решено

Архитектура: гибрид. Строгий набор компонентов дает нативные объекты и
покрывается тестами, а люк `data-raster` растрирует произвольную графику
(схемы, иконки) картинкой, оставляя текст поверх редактируемым. Подробно в
[01-architecture.md](01-architecture.md).
