# HTML -> редактируемый PPTX: как устроен MPGA

Задача: превратить HTML-презентацию в PPTX, где текст и фигуры редактируются
как родные объекты PowerPoint, а не вставлены картинкой.

Текущий план и состояние — [06-plan.md](06-plan.md). Документы 01–05 описывают
питоновский прототип, с которого всё началось (теперь он в `legacy/`), и
остаются как история решений: геометрия, единицы и грабли в них верны и
перенесены в рабочий движок `src/engine/`.

## Что решено

Архитектура: гибрид. Строгий набор компонентов дает нативные объекты и
покрывается тестами, а люк `data-raster` растрирует произвольную графику
(схемы, иконки) картинкой, оставляя текст поверх редактируемым. Подробно в
[01-architecture.md](01-architecture.md).
