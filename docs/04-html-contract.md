# Контракт HTML (набросок)

Черновик, не реализован. Задает, что агенту разрешено писать и что движок
гарантирует. Основан на том, что прототип уже умеет извлекать (см.
[02-converter.md](02-converter.md)). Финальную грамматику согласовать до кода.

## Форма документа

Один HTML-файл. Каждый слайд это `<section class="slide">`. Размер слайда
фиксирован пропорцией 16:9, базовая ширина 1160px. Внешние отступы, тулбары,
навигация в файл не входят: движок берет только `section.slide`.

## Основной путь: компоненты

Ограниченный набор классов, каждый дает предсказуемый нативный объект.
Раскладку внутри слайда задает CSS grid и flex, как в прототипе.

| Класс / элемент | Назначение | Объект в PPTX |
| --- | --- | --- |
| `h1`, `h2` | заголовки | текстовый блок |
| `p` | абзац | текстовый блок с переносом |
| `.ey` | надзаголовок (eyebrow) | текстовый блок |
| `.card` | карточка в сетке | фигура + текст внутри |
| `.item` | строка списка | фигура + текст |
| `.note` | выноска с боковой полосой | заливка + полоса + текст |
| `img`, `.image` | растровая картинка | картинка |
| `[data-icon]` | иконка из набора | картинка (растр) |

Правила, которые проверяет валидатор (предложение):

Цвета только hex или rgb. Шрифт из разрешенного списка (в прототипе Arial).
Позиционирование через grid и flex, `position:absolute` только внутри
компонентов схемы. Текст лежит в листовых элементах (`b`, `small`, `span`, `p`),
не в контейнерах с вложенными блоками. Единица размеров px.

## Люк: data-raster

Для нестандартной графики (своя схема, декоративный SVG) элемент помечается
`data-raster`. Движок скриншотит его картинкой и вставляет как есть. Графика в
такой картинке нередактируема.

Текст внутри `data-raster` по умолчанию гасится перед скриншотом и кладется
поверх нативным, чтобы подписи схемы оставались редактируемыми. Отключение этого
поведения (вся область строго картинкой) задать отдельным атрибутом, например
`data-raster="flat"`.

Так в прототипе сделаны диаграммы и кот. Механика в [03-lessons.md](03-lessons.md),
раздел про текст диаграмм.

## Что движку недоступно

Тени (в прототипе снимаются). Градиенты (нужно решение: заливкой или растром).
Переносы слов внутри коротких меток: движок их не переносит намеренно, поэтому
текст метки должен помещаться в свою ширину. Произвольные веб-шрифты без
установки в систему, где открывают PPTX.

## Пример слайда (по прототипу)

Сетка из трех карточек. Так выглядит вход основного пути.

```html
<section class="slide">
  <div class="ey">Слайд 2 · Классификация</div>
  <h2>Основные группы сетевых ресурсов</h2>
  <div class="note">Разные типы ресурсов решают разные задачи.</div>
  <div class="cards">
    <div class="card"><span data-icon="globe"></span><b>Веб-сайты</b>
      <small>Многофункциональные системы</small></div>
    <div class="card"><span data-icon="library"></span><b>Библиотеки</b>
      <small>Коллекции документов</small></div>
    <div class="card"><span data-icon="database"></span><b>Базы данных</b>
      <small>Организованные массивы</small></div>
  </div>
</section>
```
